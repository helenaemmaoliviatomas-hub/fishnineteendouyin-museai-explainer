# 交付与发布

## 交付格式

- 每支成品一个 zip，4 个文件：视频 + 1080x1920 竖版封面 + 1440x1080 横版封面 + 文案。
- 放在交付目录（比如你的项目文件夹）。
- 文案是可直接复制的文本：标题、正文、话题标签；公众号那句只写在文案里，比如：“更多在公众号 [你的公众号名]，搜一下就有。”
- 交付时附一句：逐帧验过什么、什么没验过（比如声音听不见，口音和清晰度由发布者判断）。

## 发布

- 抖音 09:00 发布，周二 / 周四 / 周六。
- 发布者自己发布；发布提醒只是提醒，绝不走浏览器替发布者发。
- 项目空间里的资产 / 项目 / 分段，交付物、规则或人物变了的当天就同步，不要等。

## 数字核对

- 计数、时长、价格、数据，写之前先核对出处；不要凭记忆写数字。
- 每支做完复盘一次：做了什么、做对了什么、做错了什么和为什么、一条能防住它的规则，当天写下来。
